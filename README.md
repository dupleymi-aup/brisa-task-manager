# Brisa Task Manager

![welcome-brisa](img/welcome-brisa.png)

**Brisa Task Manager** — это кросс-платформенный менеджер задач, построенный на фреймворке **Brisa**. Приложение позволяет пользователям создавать, отслеживать и управлять задачами с аутентификацией, фильтрацией и сортировкой.

## 🛠️ Технологии

- **Brisa** — современный веб-фреймворк для создания full-stack приложений с использованием серверных компонентов и веб-компонентов
- **JSX/TypeScript** — для написания как серверных, так и клиентских компонентов
- **Web Components** — для создания переиспользуемых элементов интерфейса
- **Signals** — для обработки событий в реальном времени
- **Tauri** (по желанию) — для создания кросс-платформенных приложений

Project created with [Brisa](https://github.com/brisa-build/brisa).

## 🚀 Установка и запуск

### 1. Клонировать репозиторий

```bash
git clone https://github.com/username/brisa-task-manager.git
cd brisa-task-manager
```

### 2. Установить зависимости

```bash
npm install -g bun
bun install
```

### Разработка

```bash
bun run dev
```

### Сборка

```bash
bun run build:fix
```

> На Windows требуется `build:fix` для исправления путей с обратными слешами (известная проблема Brisa 0.2.15)

### Запуск production

```bash
bun run start
```

### Тестирование

```bash
bun test
```

## ⚙️ Функциональные возможности

- **Создание и управление задачами**: добавление, редактирование, удаление задач с приоритетами, сроками и тегами
- **Фильтрация и сортировка**: по статусу, приоритету, тегам, поиску; сортировка по дате, приоритету, названию
- **Аутентификация**: встроенная система входа/регистрации с сохранением состояния
- **Редактирование inline**: двойной клик по задаче для редактирования прямо в списке
- **Экспорт/импорт**: задачи можно экспортировать и импортировать в JSON
- **Адаптивный дизайн**: корректное отображение на мобильных устройствах
